Privacy Policy: Hermes YouTube

Last updated 27 October 2026

Hermes YouTube is a personal tool made by Nagun Haridasan. It uploads videos to, and reads statistics from, his own YouTube channel. It is not offered to the public and has no other users.

What it accesses

Through the YouTube Data API, with permission given on Google's sign-in screen, the tool:

  • uploads videos (title, description, tags, thumbnail, privacy setting) to the signed-in channel;
  • reads the channel's basic details and statistics (subscribers, views, likes) and its latest videos;
  • reads recent public comments on the channel's videos, to show a short summary.

It does not edit or delete videos or comments, post comments, or access any other Google service.

Where data is kept

The sign-in token is stored only on the owner's own computer. A local log records each upload (date, video link, title, privacy). Nothing is sent to any server other than Google's own YouTube API, and there is no website backend or database.

Sharing

No data is sold, shared with third parties, used for advertising, or used to train AI models. Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions or through Google security settings. Revoking it stops the tool immediately; the local token is then useless.
